# 战斗反馈与数值显示

## 本轮范围

- 保留全部配方，集中呈现风扇—火炮—棱镜、喷火—冰霜—电弧、火炮—风扇—电弧三个组合。
- 贯穿炮和三道平行炮分别发动。折射炮不会因同侧另一条风扇联动而变成三联贯穿炮；原有多辅助伤害倍率保留。
- 冷目标命中冷热爆破时触发局部碎冰；电涡牵引线对应控制范围内的普通敌人。普通命中取消镜头震动，UI保持固定。
- 炮击、贯穿、折射、冰裂、放电分别限流混音；喷火底音在暂停、补给、工坊、切后台或关闭声音时淡出。
- 敌潮按普通、密集、喘息三波循环调整刷怪倍率。2026-09-07统一采用已接受的[难度曲线](difficulty-pacing.md)：刷怪基准从1.8/秒起步，40秒到3/秒；特殊敌人按候选版时刻逐步引入，首次出现仍显示提示。
- 补给中的词条保持种子决定的随机顺序；选择行为改装不额外生成敌群。所有补给均满足废料门槛和至少12秒战斗间隔。
- 即将撞车的敌人优先于首领，同一优先级内保留目标锁定。首领保留冲击倒计时、蓄力和突破提示；首次击破的阶段展示并入下一次正常补给，按正常次数推进门槛。
- 冷热爆破恢复候选版的火伤和持续灼烧，冷目标加倍与碎冰视觉保留。

## 数值口径

装甲和护盾使用两个独立槽，各有边框、填充和当前值／上限。护盾耗尽后保留空槽。

工坊显示选中车厢的当前标称攻击参数；车厢图鉴显示基础参数。参数区分单发、多弹道、延时连射、最多命中目标数、区域结算和维修／充盾量，不把面板伤害当作实际DPS。标称值不包含敌方抗性和单独发动的联动。

手绘伤害跳字使用独立笔迹几何，按元素配色。敌人护盾吸收、敌人实际掉血、列车护盾吸收和装甲损失分别显示。敌人跳字以扣除抗性和屏障后的实际掉血为准，并限制在目标剩余生命内；例如26伤害击杀24血敌人，跳字24。小数显示到一位。

同一目标同类伤害在120毫秒窗口内合并，不同目标不合并。数字有寿命和容量限制，密集位置避让；底栏“跳字”开关保存在本机。死亡页主要受损来源按列车累计实际装甲损失计算，不从最终编组推测。

## 验证

- `npm test`：战斗规则、暂停、倍速确定性、首领阶段补给及特殊敌人。
- `node --experimental-strip-types tests/combat-feedback.test.mjs`：独立贯穿／折射、真实牵引、冷热爆破、选敌、实际伤害与攻击参数。
- `node --experimental-strip-types tests/damage-numbers.test.mjs`：同目标合并、目标隔离、装甲／护盾分离、寿命和容量。
- `npm run test:panels`、`npm run typecheck`、`npm run build:web`。
- `tools/check-feedback.mjs URL`：Playwright手机390×844及桌面1440×900定点渲染；额外检查双槽、实际护盾／装甲损失、车厢参数、阶段补给和暂停音量。通过 `PLAYWRIGHT_PATH` 指定可用Playwright包；默认使用已安装Chrome。

截图和机器收据保存在 `artifacts/combat-feedback/`。这些是人工布置的渲染与规则定点场景，不是自然游玩、玩家识别率、平衡性或移动设备帧率测量。
