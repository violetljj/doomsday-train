## 主线规则

- 首次补给仍需8废料；前六次累计门槛为8、28、55、95、150、220，此后每次所需新增废料为100、110、120……。不再固定每60废料发一次。
- 两次补给至少间隔12秒战斗时间；超额废料保留。补给、工坊和暂停冻结等待时间。废料达标但仍需等待时，HUD显示补给整备秒数。
- 新生成普通敌人的血量系数：`g = max(0, (t - 20) / 20)`，`H = 1 + 0.1g + 0.01 max(0, g - 3)^2`，t为战斗秒数。前20秒不涨血，随后连续增长，80秒后逐步加快。护盾怪屏障、分裂幼体共用这一系数；已在场敌人的最大血量不随换波重算。
- 普通怪基础血量24不变；在0/40/100/180/300秒，新生普通怪血量为24/26.4/33.84/49.2/86.64。旧公式对应24/31.68/43.2/58.56/81.6。前中期更缓，后期继续施压。
- 精英在40/100/160秒出现时的基础血量由1000/1750/2500改为700/1071/1554，公式为 `700 * (1 + 0.45b + 0.08b^2)`，`b = max(0, (t - 40) / 60)`。实际延后生成时按生成时刻取值。精英攻击间隔与伤害未由本任务调整。
- 刷怪基准从每秒1.8平滑升至40秒的3，随后每20秒增加0.25，基准上限7。并行任务接入的普通/猛攻/喘息波分别乘1/1.18/0.76；因此实际怪量保留波段起伏，血量本身不阶跃。
