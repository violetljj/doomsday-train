# 0.7 余晖远征优化

目标：完成美术、战斗反馈、构筑成长和单局选择的一轮整体优化，交付可直接本地试玩的 Web 版本。

## 验收范围

- 构筑：现有成长从展示接入真实伤害、辅助和废料规则；成熟的链式、火力、支援编组具有不同爆发机制，暂停、换位、重开与弹道快照保持正确。
- 玩法：站点奖励和风险明确，装配显示编组前后变化；一局有近期成长目标、成型回报和有用的失败复盘。保留五槽和实际相邻联动。
- 美术：沿用余晖防线手绘方向，优化战场地表、列车存在感、构筑特效和 HUD 层次，与现有工坊/站点美术衔接；手机画面不重叠、不遮主要操作。
- 区域：12 个主题，每区 60 秒；完整左右刷怪通道保持全宽开放。地域特色由地面材质、嵌入式遗迹和光影形成，避免把场景道具堆在两侧。
- 局外：3 款不同主动核心的车头、4 项整备选择、基于已有游玩记录的模块解锁和本地保存；车头在战斗中实际出现并发动技能。
- 敌人：9 种独立轮廓与行为提示，旧敌人同步换图；攻击、元素受击、护盾与构筑爆发对应实际规则。
- 文字：加载项目自带标题、正文字体；伤害数字采用原创 Afterglow Wake v6 字族，替换用户否定的 v2 墨笔字及区分度不足的 v3，按五种情景区别字重、颜色、标记与运动，检查整串排版和手机尺寸。
- 反馈：爆发、受击与精英蓄力使用清楚而有限的视觉和声音提示；关闭镜头动态时保持可读。
- 稳定性：核心规则、面板、站点与开局专项测试、类型检查、实际 Web 构建；真实浏览器点击覆盖开局、装车、站点、换位、暂停、重开，并检查成熟构筑和结算画面。
- 节奏：相同种子与策略的优化前后模拟，另以代表构筑诊断成型效果；结果仅是开发策略证据，不宣称真人留存或抖音真机通过。
