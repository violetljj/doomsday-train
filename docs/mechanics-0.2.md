# 0.2 机制设计

本轮按用户“扩展游戏机制，美术后续慢慢优化”的方向实现。目标是让选择影响后续战斗，并让结算能看出本局搭配。

## 本局成长

8秒装配风扇是固定的第一次火力变化。18秒从三种支援中选一节：电弧兼顾多个敌人，冰霜控制靠近列车的普通敌人，维修提供持续恢复。支援自动接到风扇车之后。

25秒保留双生与巨型的主炮选择。40秒、58秒从六项强化池随机抽出三项供选择，每项最多两级。强化池包括伤害、主炮冷却、龙卷半径、击杀爆炸、支援冷却和装甲上限。随机抽卡与战斗共享固定种子，重开换种子；相同种子与相同选择可复现。

可尝试的搭配：

- 电弧 + 支援超频：更频繁地处理多个敌人。
- 双生 + 殉爆弹头：以高频击杀引发范围爆炸；爆炸击杀不会继续递归引爆。
- 巨型 + 扩散风道：更大范围的龙卷控制和伤害。
- 维修 + 强化装甲：增加可用装甲并逐步恢复，代价是没有额外支援伤害。

强化影响真实规则。已经发射的龙卷保存生成时的半径与伤害，后续强化改变新攻击。修复不超过当前装甲上限，强化装甲会明确立即修复25点。

## 关底战

70秒破阵者入场，1000生命，体型对应48逻辑单位碰撞补偿，免疫牵引、击退和减速。主炮优先瞄准首领，普通尸群继续靠近列车。首领每4.5秒冲击一次，造成16装甲伤害；血条与蓄力提示展示进度。

首领死亡立即胜利。装甲归零失败，90秒仍未击败首领则超时。当前首领是检验火力和续航的第一种关底规则，冲击无需躲避操作。

## 验证重点

选择是否容易理解、支援生效是否可见、两次随机强化是否让人想尝试不同搭配，是接下来试玩要回答的问题。开发检查覆盖实际伤害、减速、恢复、爆炸不递归、上限、暂停、倍速一致性、首领胜负和重开清理；数值可通关不等同于各搭配已经平衡。
