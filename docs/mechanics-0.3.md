# 0.3 四槽车厢联动

用户确认：每种车厢本身有作用、槽位有限、仅相邻两辆联动、三辆可产生两条联动、顺序可能改变效果、不同组合有不同优势和对策弱点、发现组合有惊喜，词条影响车厢或联动。

## 结构规则

四个功能槽不包含机车。从车头到尾读作1→2→3→4。每辆车独立攻击或控制，相邻两辆额外发动联动。同类独立工作；空槽切断连接。一个中间车可以参与两个连接，不把A—B—C误算为A—C也相邻。

工坊允许选择两槽交换。获得新车后点击目标槽装入或替换，也能放弃新车。替换没有额外仓库，旧车和自身改装拆除。战斗中可主动进入工坊；选卡和工坊都冻结战斗，操作不收费。

## 发现、词条与对策

游戏使用确定性配方，随机性在补给获取。第一次发动一个未知组合才加入图鉴，预览或在工坊试摆不会解锁。图鉴存在本机localStorage，不跨设备同步，也不包含数值加成。

六种词条分别升级现有火炮、喷火、风扇、电弧、冰霜车，以及当前相邻联动。车厢等级随对象换位，不附着在槽位上。词条最多两级，全部目标满级后不再提供无效词条。当前只做可读的数值与联动强度变化，更复杂的词条改写不在本轮范围内。

重甲、耐火、绝缘分别针对物理、火、电；冻结与推力作用于普通敌人，首领免控。敌人颜色及上方标记提供提示。此版本证明机制差异，不能据此宣称没有强弱流派。

## 成长与结束

击杀推动废料增长，六次补给门槛8/24/48/80/120/170。新部件立即进入工坊，让玩家先安排顺序再恢复战斗。60秒首领登场，80秒仍未击败则超时；装甲归零失败。

实玩重点：能否预想一次换位的影响、是否看清两条联动同时作用、发现配方后是否想在下一局主动凑齐。检查默认2×，只针对新增节点与实际故障复查。
