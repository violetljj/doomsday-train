# 0.5 八种车厢与无尽波次

本版继续使用五个功能槽、相邻职责联动和手动车序调整，扩展车厢、词条与敌人对策，并将限时关卡改为无尽模式。美术和网站发布由主线另行接入；本文记录规则实现及模拟检查，不代表Web交互或玩家体验验收。

## 八种车厢

| 职责 | 车厢 | 独立作用 |
| --- | --- | --- |
| 进攻 | 火炮车 cannon | 实体炮弹，基础26伤害、0.66秒间隔。 |
| 进攻 | 喷火车 flame | 240射程扇形火焰，基础6伤害、0.2秒间隔；命中点燃目标。 |
| 进攻 | 电弧车 tesla | 550范围内最多三个目标，基础16电伤、0.95秒间隔。 |
| 进攻 | 轨道炮车 rail | 贯穿弹，基础42物理伤害、1.1秒间隔。 |
| 增益 | 风扇车 fan | 零伤害风压，推开普通敌人。 |
| 增益 | 棱镜车 prism | 零伤害折光脉冲；相邻时分裂进攻车攻击。 |
| 减益 | 冰霜车 cryo | 245范围低伤冰霜波，基础4伤害、1.6秒间隔，并减速。 |
| 减益 | 蚀酸车 acid | 260范围酸雾，基础3酸伤、1.4秒间隔，腐蚀持续3秒。 |

进攻＋增益、进攻＋减益才产生联动；四种进攻与四种辅助形成十六种配方，同对车前后交换效果相同。增益＋减益、进攻＋进攻及同类相邻不联动。每条边由进攻车执行，辅助传能先从辅助槽指向执行槽；五槽最多四条边，共享辅助与集中辅助均保留。

## 十五种改装与取舍

所有改装作用于领取时现存的目标车，最多两级；`Car.mods` 保存每项实际等级，随旧车对象移动，替换新车不继承。旧有五类车厢升级、三个新车升级提升车厢 `level`，基础伤害按每级35%增长，相邻联动还计入双方等级；同步传动提升联动等级，每级增加25%联动伤害。

| 改装 | 目标与真实变化 |
| --- | --- |
| 扩膛弹药 caliber | 火炮车等级。 |
| 高热燃料 fuel | 喷火车等级。 |
| 增压叶轮 pressure | 风扇等级，增加推力与对应联动伤害，独立伤害仍为零。 |
| 高压线圈 voltage | 电弧车等级。 |
| 低温冷剂 coolant | 冰霜车等级。 |
| 同步传动 resonance | 所有相邻联动等级。 |
| 磁轨增压 railpower | 轨道炮等级。 |
| 精磨晶面 prismfocus | 棱镜等级，增强对应联动，独立伤害仍为零。 |
| 浓缩蚀剂 acidpotency | 蚀酸车等级。 |
| 自动供弹 rapid | 火炮基础攻击间隔每级乘0.8。 |
| 延伸喷管 reach | 喷火基础与火流联动射程每级增加25%；基础射程240→300→360。 |
| 快速放电 surge | 电弧基础攻击间隔每级乘0.8。 |
| 并列磁轨 lanes | 轨道炮基础弹道数1→2→3，弹道平行横移。 |
| 霰射弹仓 scatter | 火炮基础弹道数1→2→3，向两侧散开。 |
| 序列连发 burst | 火炮每次基础攻击追加一轮或两轮延时齐射。 |

多弹道改变覆盖范围，也承担单发代价：`lanes`、`scatter` 的单发伤害与碰撞半径均除以弹道数平方根。总伤害潜力增加，但单发更弱、更小，散射并不保证所有炮弹都命中单一目标。

`burst` 与同时散射不同。第一轮立即发出，追加轮分别在0.12和0.24秒后发出；两轮时每发伤害乘0.72，三轮时乘0.6。散射与连发可以组合，使用相同减伤规则。队列保存发射时的车厢ID、瞄准角、伤害与弹体大小；工坊和暂停冻结队列，车厢移位后从新槽发射，真正拆除车厢才取消其待发攻击。队列上限60发，不借由后续升级重算旧攻击伤害。

词条强调射程、覆盖与节奏的可见差异，不将增加弹数直接做成无代价的倍增伤害。修改基础攻击节奏或数量的词条不刷新已有联动冷却；射程词条同时影响相应火流联动。

## 无尽波次与持续补给

`wave` 每20秒增加1，起始第1波。普通敌人生命随波次按 `1+0.16×(wave-1)` 增长；生成速率在早期节奏上每波增加0.35只/秒，额外速率最多5只/秒。活动普通敌人最多99，为一名首领保留名额；含首领总计最多100。

第3波（40秒）开始出现首领，此后每隔三波再生成一名。同一时刻只保留一名首领；若前一名仍存活，下一次生成延后，生成后重新间隔三波。首领生命以第3波1000为起点，每晚一波增加250，仍每4.5秒蓄力冲击装甲。击杀记入 `boss_killed`，不会结算胜利；80秒不会结束，只有装甲归零产生失败结算。

前六次废料门槛仍为8、24、48、80、120、170，之后每累计60废料再补给：230、290、350……持续循环。最初四次提供车厢；每组保留至少一个进攻和一个辅助选项，首次仍固定风扇、冰霜、一个进攻车。之后提供两种车厢和一个当前合法、未满级的词条；若所有可用词条已满，退回车厢选项，可选择替换或放弃。

五槽与插入规则保留：空槽直接装入，未满时点击已有车厢优先向右找空槽插入，否则向左插入；全满才替换。旧车ID、等级、改装与配对冷却随车保留。发车使用 `start(seed, deferEncounter)` 与 `startEncounter()`，驶入表现结束前不会推进模拟或提前刷出敌人。

## 敌人机制与对策

原有kind0普通、kind1快速、kind2重甲、kind4耐火、kind5绝缘保留，晚期混合生成使用互不重叠的随机区间，不会被新增敌人覆盖。

| 类型 | 行为 | 对策 |
| --- | --- | --- |
| kind6 护盾怪，第2波起 | 有额外20×波次生命倍率的有限屏障，先吸收伤害。 | 腐蚀时屏障仅吸收本次伤害的25%，剩余伤害穿盾。 |
| kind7 孵化怪，第3波起 | 被击杀后产生最多两只快速幼体，仍受实体上限限制；幼体不再孵化。 | 穿透、范围与控制处理幼体；母体与幼体各自实际死亡才记废料。 |
| kind8 再生怪，第4波起 | 每2秒恢复最大生命的8%，不超过上限。 | 点燃期间不能回复；喷火基础和相应火流能维持燃烧。 |

腐蚀还会在持续期间取消重甲的物理减伤、耐火的火焰减伤和绝缘的电击减伤。腐蚀不是永久改写抗性；计时结束后恢复原有减伤。新增酸伤作为独立伤害类型处理。

## 表现接口与本轮模拟证据

`getCarRange(slot)` 返回该车当前基础攻击真实范围，喷火含射程改装。新增效果类型为 `acid`、`prism`、`regen`、`shield`、`brood`；其他攻击复用既有 `pierce`、`shatter`、`conduction`、`focused-flame`、`link-feed` 和 `link-shot`。弹体可携带 `corrosion/slow/freeze/knockback/frozenBonus` 快照，`enemy.corrosion/barrier/regenClock` 可读。

本轮 `npm test` 通过，Combat/Catalog 使用Creator随附TypeScript 5.8进行严格独立类型检查通过。覆盖八种独立功能、十六配方正反两序、词条实际射速/射程/弹数/连发时点与快照、暂停和拆除队列、新敌人对策、持续九次补给、跨80秒和重复首领、插入与重开。自然种子137路线在1×/2×/4×下完整状态一致：第6波106.70秒装甲归零，505击杀、509废料、峰53敌人，击杀第一名首领，第二名剩约4.53生命。

该路线前四次选择风扇→电弧→冰霜→火炮，组成火炮—风扇—电弧—冰霜—火炮；后续依次快速放电、霰射弹仓、高压线圈、快速放电、增压叶轮、序列连发、同步传动。共经历十一轮自然补给。这是有限时长的开发模拟，没有调整种子或扫参数，不是通关、玩家胜率、爽感或Web真机证据。
