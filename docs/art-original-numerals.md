# Afterglow Wake 原创伤害数字

2026-09-10：用户指出 v5 虽能阅读，仍然粗糙、缺乏设计感。本轮从字形轮廓重新绘制，当前运行资源为 v6。

- 源：`tools/generate-swept-digits.mjs`。0–9、点、负号均为独立闭合贝塞尔轮廓，无外部数字字体；不再对等粗中心线简单描边。
- 造型：向前伸出的尖端、粗细变化的弧线、不对称内部留白。6/9 的外弧拉成长收笔，2/7 的横画形成向前掠过的笔势，4 保持开放结构，0/8 保持清楚的内部空间。
- 图集：`assets/resources/art/afterglow-damage-digits-v6.png`，1152×640，12列×5行，96×128单元，RGBA。顺序 `0123456789.-`，行序普通、重击、持续、护盾、受伤。
- 普通：象牙色，短促弹起；重击：宽体、暖色斜向分色与更强的展开；持续：收窄并减轻倾斜、缓升；护盾：青色、细横切线与盾标；列车受伤：珊瑚色、负号和下划线、向下坠落。
- 版式：全屏至多14组，优先显示列车受伤与重击；避让包含斜体外伸、符号与浮动高度，拥挤时减少低优先级显示。实际伤害与统计不变，不把大额伤害虚称为暴击。
- 生成：设置本机 `PLAYWRIGHT_PATH` 后执行 `node tools/generate-swept-digits.mjs`；样张 `node tools/fonts/preview.mjs`，输出 `artifacts/typography/type-specimen-v6.png`。

v2–v5 保留为历史版本，Game 不再加载。样张只能验证字形，最终检查使用浏览器真实运行画面与明确标注的受控战斗展示。
