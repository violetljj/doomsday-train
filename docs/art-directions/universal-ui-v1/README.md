# 通用视觉语言 v1：生图探索

生成方式：内置 imagegen。concept.png 为设计探索，不是已实现游戏截图。

方向：深色搪瓷仪表、克制金属包边、浅色正文；金色表示选择/投资，青色表示供能，珊瑚红表示危险。三个背景使用相同控件设计。底部展示风压贯穿炮基础、中级、高级、超频的结构与能量路径变化。

评审：跨背景骨架一致，色彩与材质可作为实现参考。生图增加了速度表、路线条、里程补给和虚构卡片数值；这些不代表现有玩法或新需求，不应照搬。实际实现仍使用时间、装甲、废料经验与词条补给。生成的列车造型不是资产替换指令。移动端需要简化细小铆钉和边框。
