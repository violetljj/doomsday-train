## 现场证据

内置浏览器 390×844，最终构建定点场景：城市初始单车、极光五槽、明亮盐滩五槽。实际查看截图，HUD 文案与装备图标未溢出；console error 列表为空。

实际点击：编组按钮 -> workshop；第三装备槽 -> workshop 且 selected=2；工坊主按钮 -> combat；底栏暂停 -> paused。

发现并修复：工坊标题粉色底是去底材质丢失，恢复材质后截图确认消失。主按钮由暗面板改为实际生成的黄铜按钮素材，截图确认。

验证：typecheck、随包字体覆盖、build:web、git diff --check。面板规则测试在之前面板结构变化后已通过，当前 HUD 排布不改变战斗规则。定点注入五槽与时间不是自然一局或真机性能测试。
