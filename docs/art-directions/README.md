## 比较时看什么

优先比较界面与战场是否属于同一套世界、车厢缩小后的辨识度、敌人与特效的明暗层次、卡面与实战装备的一致性。四版都保留五个功能车厢的核心构图。

概念图中的文字、数值、地图、等级和联动说明不是机制规格，存在生成误差。例如部分图片标注了非相邻组合或错误角色，不能据此修改游戏规则。落地仍遵循已确定的相邻联动与车厢分类。图片仅展示静态效果方向，尚未验证动画和手机性能。

参考阅读：[PlatinumGames 官方《UI Design in NieR:Automata》](https://www.platinumgames.com/official-blog/article/9624)。参考作品用于气质与视觉语言探索，不使用其角色或标志。
