# 余晖方向：统一视觉语言修订

2026-09-10。用户指出整体复古、搭配不协调，要求参考《女神异闻录》与《十三机兵防卫圈》的设计理念。旧版书法标题、金属切角字、数码管细线和拼贴面板不再作为当前统一方案。

## 参考结论与本作取舍

- [《十三机兵》制作人访谈，PlayStation Blog](https://blog.playstation.com/2020/08/10/how-atlus-x-vanillaware-bring-2d-art-to-life-in-13-sentinels-aegis-rim/)：现代场景通过夕照、霓虹、逆光与分层空间获得表现力。用于本作：手绘机械和地面继续承担材质，光色组织视线，信息层减轻遮挡。颗粒、裂纹和边框不能代替主光与空间层次。
- [P3R 开发者访谈，Famitsu](https://www.famitsu.com/news/202311/29325647.html)：设计概念会同时影响画面与运动；界面需要先整理必要信息，再实际放入游戏检验。用于本作：统一以“余晖下持续前行的机械秩序”为主题，按钮、成长线和车厢联动沿清晰路径组织，动作迅速给反馈并回到稳定阅读状态。
- [P5 导演谈菜单，Eurogamer](https://www.eurogamer.net/articles/2017-04-19-lets-talk-about-persona-5s-menus)：形式服务于作品自身的反叛主题。用于本作的原则是明确主导主题；不直接混入 P5 红黑剪贴或 P3 水下玻璃的具体造型。

这些迁移判断是本项目设计取舍，不是对原作开发者观点的逐字引用。

## 本轮已实施规则

1. **共同字族。** 标题与正文使用 Noto Sans SC 的600/450静态字重子集，均重命名为 Afterglow Modern；菜单、工坊、状态与正文不再混用书法和手写楷体。保留完整OFL授权与固定上游来源。
2. **原创曲线数字。** Afterglow Wake v6 的0–9、小数点和负号由独立贝塞尔路径绘制。闭合轮廓包含粗细弧线、尖端与不对称留白，普通象牙白、重击暖桃宽体、持续淡紫细体、护盾青色带盾标、装甲损耗珊瑚红负号与短下划线。去除金属渐变、挤出阴影和数码管轮廓。
3. **轻量信息层。** 战斗头部由硬底板改为向战场淡出的信息层；耐久、当前编组、下一目标各有固定位置。顶部主要信息边界从y320收至约y400，减少遮挡。
4. **一致的操作面。** 工坊、车库、暂停等共享清晰字形、轻圆角底板与细线边缘；取消不规则纸片叠色、三层笔刷底衬和按钮刮痕。手绘材质留给场景与设备。
5. **按重要性呈现反馈。** 同一伤害通道优先显示最近浮字；全屏最多14组，其中重击最多4组。数值避让按当前显示边界计算，低优先级显示让位，不改变战斗伤害或统计。持续喷火与状态持续伤害使用细体通道。

## 图像与实际实现的区别

`afterglow-cohesive-battle-concept.png` 是使用内置 imagegen 生成的完整风格参考。输入为已选 C2 风格板与运行版本截图；要求全宽开放地表、手绘机械、轻量HUD和五种伤害信息。它用于整体构图对照，未作为整张游戏贴图接入，也不是实机验收截图。

当前代码接入：`Game.ts`、`PanelRenderer.ts`、`DamageNumbers.ts`；生成器 `tools/generate-swept-digits.mjs`、`tools/build-modern-fonts.py`。实际浏览器结果保存在 `artifacts/optimization-20260910/cohesive-ui/`。原有12区域、9种敌人、3个车头和构筑规则继续存在。
