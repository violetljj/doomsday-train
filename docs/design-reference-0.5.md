## 手绘美术约束

用户确定以《十三机兵防卫圈》的手绘感作为参考，并特别要求不均匀色块。当前项目继续使用 `C2-afterglow-details.png` 的余晖方向：靛紫冷影、暖桃光、暖白纸色、少量淡青提示。

新增图像必须使用实际手绘色块、冷暖叠色和铅笔轮廓，避免只换颜色或覆盖噪点。卡片、按钮和状态条用不齐边缘与明确大色块；文字保持稳定清楚。新车厢与怪物图集进入实战与卡面共用，不只展示立绘。资产提示词及原图来源另见 `art-directions/handpainted-ui-v2.md` 与 `art-directions/expansion-v05.md`。

## 本轮验证重点

检验实际攻击间隔、射程、同时弹道和延时连发的区别；首领死亡和80秒之后仍能继续；补给不会在第六次停止；新敌人有明确对策与不同轮廓。规则测试只能证明机制工作，朋友试玩反馈才用于判断构筑是否好玩。
