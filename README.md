# 末日列车

项目根目录：`E:\Doomsday Train`。Cocos Creator 3.8.8 原型，当前0.4.0。

核心方向：独立车厢＋有限槽位＋相邻联动。玩家通过选择、换位和替换车厢，搭建不同的自动战斗列车。当前面向本地试玩，后续目标为抖音小游戏。

## 立即试玩

双击 **玩一下.cmd**。它启动本地服务并打开浏览器；试玩时保留启动窗口，结束后按 Ctrl+C 停止服务。没有Web构建时会自动调用本机Creator构建。

默认使用固定地址 `http://127.0.0.1:61401/`，让同一浏览器的图鉴记录在下次启动时继续保留。独立开发预览可运行 `node tools/serve.mjs 0` 使用临时端口。

1. 发车时第一功能槽为火炮车，另有四个空功能槽位。
2. 击破敌人收集废料，达到补给门槛后暂停并三选一。前四次获得车厢，后两次混合提供车厢与可用改装词条。
3. 新车进入工坊后，点击空槽装入，或点击旧车替换；也可以放弃本次新车。
4. 工坊中点两个槽位交换位置，包含空槽。点击出发恢复战斗。
5. 战斗底部的 **改装 ↔** 随时暂停并打开工坊，可以重新安排已有车厢。
6. 60秒出现首领，80秒前击败它获胜；装甲归零或超时失败。

底栏 **倍速 ×1** 按钮循环切换1×/2×/4×。重开保留本次倍速，刷新回到1×。按用户要求，开发中的浏览器检查默认2×；只有检查正常动画节奏时短暂切1×。

## 五种车厢与五个槽位

| 车厢 | 职责 | 独立作用 |
| --- | --- | --- |
| 火炮车 | 进攻 | 发射实体炮弹。 |
| 喷火车 | 进攻 | 扇形持续喷火。 |
| 风扇车 | 增益 | 零伤害风压，推开普通敌人。 |
| 电弧车 | 进攻 | 自动电击多个目标。 |
| 冰霜车 | 减益 | 低伤害冰霜波，主要减速普通敌人。 |

机车不占功能槽。五个功能槽位从车头到车尾排列；每节车厢独立工作，只有相邻的进攻＋增益、进攻＋减益产生联动，由进攻车执行。进攻车之间、风扇与冰霜之间不产生联动，空槽不跨越。

当前共六种配方，同一对车前后互换效果一致。火炮—风扇—喷火让一个风扇支援两侧；风扇—火炮—冰霜让两种辅助集中于一门炮。各联动独立触发，不互相覆盖，最多同时四条。工坊明确显示谁辅助谁，战斗连接动画指向执行武器。

未知配方先给线索，战斗中真正发动后揭晓名称与效果，并保存在本机图鉴中；换位预览不会提前解锁。已有的有效发现保留，已移除配方不再占图鉴数量。

部分敌人有对策属性：重甲削弱物理伤害，耐火削弱火伤，绝缘削弱电伤。首领免疫控制。当前是验证差异的起始数值，尚未证明各流派平衡。

## 改装与补给

击杀废料累计达到8、24、48、80、120、170时获得补给，共六次。前4次是车厢三选一，可填满初始火炮后的四个空槽；后2次通常为两辆车与一项可用词条。词条只针对当前拥有且未满级的车厢类型，或已有且未满级的联动；无可用词条时提供三个车厢选项。

首次补给固定有风扇、冰霜与一辆进攻车，初始火炮可直接选择相邻辅助。

车厢词条提升对应现有车厢，最多两级；车厢换位保留等级，替换会拆除旧车及其改装。联动词条提升相邻联动，最多两级。已射出的攻击保存发射时的伤害，不因换位或替换瞬间改变。

工坊、选卡、暂停期间冻结战斗与成长。相邻关系决定后续发动的联动，已经飞出的攻击会按自身寿命结束。

## 开发与检查

- `npm run build:web` 更新实际试玩构建。
- `npm run typecheck` 使用Creator自带TypeScript检查工程。
- `npm test` 验证独立车厢、相邻关系、真实联动、抗性、改装、操作保护、废料补给、暂停、倍速、首领与重开。
- `node --experimental-strip-types tools/balance-check.mjs` 运行固定策略开发诊断。

在Cocos Dashboard导入本目录，使用Creator 3.8.8打开 `assets/scenes/Main.scene`。核心规则位于 `assets/scripts/Combat.ts`，配方与词条位于 `assets/scripts/Catalog.ts`，战场和输入位于 `assets/scripts/Game.ts`，菜单、工坊、补给与图鉴位于独立的 `assets/scripts/PanelRenderer.ts`。构建输出在 `build/web-mobile/`，日志在 `logs/`。

当前交付形态为Web原型。验证范围和历史结果见[验证记录](docs/test-record.md)，检查效率要求见[验证流程](docs/validation-workflow.md)。尚未执行抖音开发者工具和抖音真机验证；本轮美术接入不等于已通过本轮QA，具体结果以验证记录为准。玩家反馈与规则测试分开记录。
