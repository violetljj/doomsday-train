# 末日列车

项目根目录：`E:\Doomsday Train`。Cocos Creator 3.8.8 原型，当前0.7.0余晖远征版。

核心方向：独立车厢＋有限槽位＋相邻联动。玩家通过选择、换位和替换车厢，搭建不同的自动战斗列车。当前面向本地试玩，后续目标为抖音小游戏。

## 立即试玩

双击 **玩一下.cmd**。它启动本地服务并打开浏览器；试玩时保留启动窗口，结束后按 Ctrl+C 停止服务。没有Web构建时会自动调用本机Creator构建。

默认使用固定地址 `http://127.0.0.1:61401/`，让同一浏览器的图鉴记录在下次启动时继续保留。独立开发预览可运行 `node tools/serve.mjs 0` 使用临时端口。

1. 主菜单可整备破晓、鸣雷、守望三款车头，分别携带火炮、电弧、喷火起始车；另有四个空功能槽位。车头不占功能槽，每20秒发动各自核心技能。
2. 列车完成驶入后才生成敌人并开始计时。击破敌人收集废料，首次补给提供车厢；从第二次起到站三选一：货场拿车厢并面对增援、军械站拿改装并面对强化重甲怪、维修站恢复装甲并放弃本次成长。站点选择与装车期间暂停。
3. 新车进入工坊后，先选择槽位，再确认装入、插入或替换。同类型还可选择合并升级，保留原车和词条。未满五槽时插入新车会优先将旧车向右移入最近空槽，右侧无空槽则向左移，保留所有旧车；满五槽时才替换。也可以放弃本次新车。
4. 安装或放弃待装新车后，在工坊依次点击两个槽位交换位置，包含空槽。点击出发恢复战斗。
5. 战斗底栏 **调整车序**、直接点击战场车厢、暂停页 **调整车序** 均可进入工坊，调整期间战斗保持暂停。点击战场车厢会选中它，再点另一槽即可交换；未领取补给时需先完成选卡。
6. 每20秒进入下一波，逐波增加敌人数量与血量。每三波出现精英；每60秒进入下一个主题区域，12区后继续循环，仅装甲归零结束。

底栏 **倍速 ×1** 按钮循环切换1×/2×/4×。重开保留本次倍速，刷新回到1×。按用户要求，开发中的浏览器检查默认2×；只有检查正常动画节奏时短暂切1×。

## 十种车厢与五个槽位

0.7加入真实构筑成长：火力编队强化武器，链式共鸣强化联动，全域支援强化辅助；满足各自三阶条件后，每充能18秒进入4秒爆发。工坊显示当前被动和编组变化，暂停、选卡和换位冻结充能。整备车库保存车头、一个起始模块及历史记录；发现3种配方可解锁废料模块，击破1个首领可解锁储能模块。详见[本轮范围与验证](docs/optimization-0.7.md)。

| 车厢 | 职责 | 独立作用 |
| --- | --- | --- |
| 火炮车 | 进攻 | 发射实体炮弹。 |
| 喷火车 | 进攻 | 扇形持续喷火。 |
| 风扇车 | 增益 | 零伤害风压，推开普通敌人。 |
| 电弧车 | 进攻 | 自动电击多个目标。 |
| 冰霜车 | 减益 | 低伤害冰霜波，主要减速普通敌人。 |
| 轨道炮车 | 进攻 | 整束磁轨光束贯穿直线敌群。 |
| 棱镜车 | 增益 | 零伤折光脉冲，分裂相邻进攻车攻击。 |
| 蚀酸车 | 减益 | 低伤腐蚀，穿透屏障并削弱抗性。 |
| 维修车 | 增益 | 每8秒修复装甲，辅助相邻武器回收。 |
| 护盾车 | 增益 | 周期补充护盾，先抵挡接触与首领伤害。 |

机车不占功能槽。五个功能槽位从车头到车尾排列；每节车厢独立工作，只有相邻的进攻＋增益、进攻＋减益产生联动，由进攻车执行。进攻车之间、辅助车之间不产生联动，空槽不跨越。

当前共二十四种配方，同一对车前后互换效果一致。火炮—风扇—喷火让一个风扇支援两侧；风扇—火炮—冰霜让两种辅助集中于一门炮。维修车和护盾车为增益型车厢，分别提供慢速修复和护盾，并能与四种进攻车形成回收/防卫联动。各联动独立触发，不互相覆盖，最多同时四条。工坊明确显示谁辅助谁，战斗连接动画指向执行武器。

未知配方先给线索，战斗中真正发动后揭晓名称与效果，并保存在本机图鉴中；换位预览不会提前解锁。已有的有效发现保留，已移除配方不再占图鉴数量。

部分敌人有对策属性：重甲削弱物理伤害，耐火削弱火伤，绝缘削弱电伤。首领免疫控制。当前是验证差异的起始数值，尚未证明各流派平衡。

护盾怪带有限屏障，蚀酸能穿盾；分裂怪死亡后产生幼体；再生怪周期回血，燃烧能压制回复。新增敌人使用不同的手绘轮廓。

## 改装与补给

现有17种词条，包括火炮攻速、喷火射程、电弧攻速、火炮散射、延时连发、轨道炮平行光束、维修量和护盾容量。多弹道会降低单发伤害与尺寸；词条随现有车厢保存，工坊点选车厢可查看。详见[0.5机制](docs/mechanics-0.5.md)与[0.5.1机制](docs/mechanics-0.5.1.md)。

击杀废料累计达到8、28、55、95、150、220时获得补给，此后依次再需100、110、120……废料。两次补给至少相隔12秒战斗时间，超额废料保留，暂停不计时。第二次起持续提供当前配置可用的词条；满槽时偏重重复车厢合并，也保留新类型供重组。受伤时提供最高恢复30点装甲的维修补给。当前成长公式与批量对照见[难度曲线调整](docs/difficulty-pacing.md)。

首次补给固定有风扇、冰霜与一辆进攻车，初始火炮可直接选择相邻辅助。

2026-09-07加入[站点选择闭环](docs/station-loop.md)。后续补给统一为三条支线，替代原有混合选卡：废弃货场给一节车厢，至下站前每刷出4名敌人追加1名普通怪；军械站提供当前可用改装（优先进攻车），恢复战斗3秒后追加1名双血量重甲怪；维修站最多恢复30装甲，不追加站点敌人。卡片提前公开具体奖励和代价，战斗顶栏显示当前支线。既有敌人继续存在，站点不清场。

前一分钟进一步加入手绘工坊的滑入／移位预览、装车就位动作、首次风扇→火炮供能说明，以及基于真实弹道的多目标贯穿反馈。站点卡同时说明当前编组可新增火力／联动、是否适合同车合并，以及重甲敌人的物理抗性。此版本需要重新试玩判断，不继承旧版生存率结论。

2026-09-07已将试玩认可的难度曲线统一到主工程：前20秒怪物血量不涨，随后平滑增长；刷怪基准40秒内从1.8/秒增至3/秒，配合普通／猛攻／喘息波段。首领突破保留提示，并入下一次正常补给。直接使用根目录的`玩一下.cmd`；独立候选副本仅保留作历史对照。

车厢和联动数值词条不限级，攻速、散射、连发等机制词条仍最多两级。插入移位、合并和手动换位保留旧车及其词条、冷却，满槽替换才拆除目标旧车及其改装。旧车对的联动冷却不会因插入或换位而刷新。已射出的攻击保存发射时的伤害，不因换位或替换瞬间改变。主菜单与工坊可打开车厢目录，查看全部10种车厢。

工坊、选卡、暂停期间冻结战斗与成长。相邻关系决定后续发动的联动，已经飞出的攻击会按自身寿命结束。

## 开发与检查

- `npm run build:web` 更新实际试玩构建。
- `npm run typecheck` 使用Creator自带TypeScript检查工程。
- `npm test` 验证独立车厢、相邻关系、真实联动、抗性、改装、操作保护、废料补给、暂停、倍速、首领与重开。
- `node --experimental-strip-types tools/balance-check.mjs` 运行固定策略开发诊断。

在Cocos Dashboard导入本目录，使用Creator 3.8.8打开 `assets/scenes/Main.scene`。核心规则位于 `assets/scripts/Combat.ts`，配方与词条位于 `assets/scripts/Catalog.ts`，战场和输入位于 `assets/scripts/Game.ts`，菜单、工坊、补给与图鉴位于独立的 `assets/scripts/PanelRenderer.ts`。构建输出在 `build/web-mobile/`，日志在 `logs/`。

当前交付形态为Web原型。验证范围和历史结果见[验证记录](docs/test-record.md)，检查效率要求见[验证流程](docs/validation-workflow.md)。尚未执行抖音开发者工具和抖音真机验证；本轮美术接入不等于已通过本轮QA，具体结果以验证记录为准。玩家反馈与规则测试分开记录。
